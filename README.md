# Nyao Scalper Web App

Mobile-first static frontend for displaying live Nyao Scalper EA signals.

## Vercel
1. Extract this ZIP.
2. Create a new GitHub repository and upload `index.html`.
3. In Vercel, import the GitHub repository.
4. Framework Preset: Other / Static.
5. Deploy.

No paid server is required for this frontend.

## Important
The current page contains demo data so the UI can be tested immediately.
The next integration step is to connect the Nyao Scalper EA to a backend/API and replace the demo object with live JSON.
